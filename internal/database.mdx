## Database model

The application uses Supabase PostgreSQL as the authoritative store. Browser reads and mutations use PostgREST and RPC with the current user JWT under Row Level Security. Security-sensitive operations run through Edge Functions with the service role after explicit identity validation.

## Entity relationships

Most business entities carry a `company_id` for tenant isolation. Policies compare it to the current user's company. Archive tables preserve historical rows even when live foreign-key targets are later removed.

- **companies** — profiles, videos, company_settings, company_video_protection_settings
- **profiles** — videos, admin_audit_log
- **videos** — access_codes, poster_images
- **access_codes** — guest_viewing_logs, playback_events, email_events
- **companies** — invited_guests, bulk_invite_jobs, bulk_invite_templates
- **bulk_invite_jobs** — bulk_invite_job_items — access_codes

## Table schemas

The schema groups cleanly by tenant identity, video management, invitations, analytics, settings, and operational data. The lists below focus on the columns that define ownership, lifecycle, defaults, and important constraints.

### Tenancy and identity

`companies` stores tenant records and upload/provider configuration.

- **`id`** — `uuid`, primary key
- **`name`** — `text`, required
- **`created_at`** — `timestamptz`, created timestamp
- **`upload_prefix_url`** — `text`, optional upload path prefix
- **`subdomain`** — `text`, optional tenant slug
- **`gumlet_collection_id`** — `text`, optional provider collection identifier

`profiles` binds authenticated users to a company and role.

- **`id`** — `uuid`, primary key, matches auth user ID
- **`email`** — `text`, required
- **`role`** — `text`, manager or admin
- **`can_access_analytics`** — `boolean`, feature flag
- **`company_id`** — `uuid`, tenant foreign key
- **`can_use_advanced_invites`** — `boolean`, feature flag

### Video domain

`videos` stores upload state, provider linkage, ownership, and archive lifecycle.

- **`id`** — `uuid`, primary key
- **`user_id`** — `uuid`, creator profile reference
- **`title`** — `text`, required
- **`description`** — `text`, optional
- **`poster_url`** — `text`, optional
- **`duration`** — numeric duration field
- **`gumlet_asset_id`** — `text`, provider asset identifier
- **`status`** — `text`, `pending`, `uploading`, `processing`, `ready`, `failed`, or `archive`
- **`created_at`** — `timestamptz`, created timestamp
- **`is_deleted`** — `boolean`, soft-delete flag
- **`company_id`** — `uuid`, tenant foreign key
- **`archived_at`** — `timestamptz`, archive timestamp
- **`deleted_at`** — `timestamptz`, hard-delete lifecycle marker
- **`upload_origin`** — `text`, upload path/source marker

`poster_images` tracks stored poster assets and their lifecycle.

- **`id`** — `uuid`, primary key
- **`company_id`** — `uuid`, tenant foreign key
- **`video_id`** — `uuid`, related video
- **`storage_path`** — `text`, object storage path
- **`public_url`** — `text`, resolved asset URL
- **`original_source`** — `text`, original remote source
- **`uploaded_by_user_id`** — `uuid`, uploader profile
- **`size_bytes`** — numeric byte size
- **`width`** — integer image width
- **`height`** — integer image height
- **`is_archived`** — `boolean`, archive flag
- **`orphaned_at`** — `timestamptz`, cleanup marker
- **`created_at`** — `timestamptz`, created timestamp
- **`usage_context`** — `text`, intended usage marker

`company_video_protection_settings` stores per-company playback protection settings.

- **`company_id`** — `uuid`, primary key
- **`signed_urls_enabled`** — `boolean`, protection toggle
- **`gumlet_sign_secret`** — `text`, signing secret
- **`signed_url_ttl_seconds`** — integer TTL
- **`watermark_email_enabled`** — `boolean`, email watermark toggle
- **`watermark_ip_enabled`** — `boolean`, IP watermark toggle

### Invitations and guests

`access_codes` stores invitation lifecycle, guest limits, and delivery state.

- **`id`** — `uuid`, primary key
- **`video_id`** — `uuid`, related video
- **`guest_email`** — `text`, required
- **`code`** — `text`, invite/access token value
- **`views_allowed`** — integer, default `10`
- **`views_used`** — integer, default `0`
- **`expires_at`** — `timestamptz`, required
- **`created_by_user_id`** — `uuid`, creator profile
- **`created_at`** — `timestamptz`, created timestamp
- **`last_used_at`** — `timestamptz`, latest consumption time
- **`company_id`** — `uuid`, tenant foreign key
- **`starts_at`** — `timestamptz`, optional access start
- **`display_timezone`** — `text`, presentation timezone
- **`job_item_id`** — `uuid`, optional bulk invite linkage
- **`latest_email_delivery_status`** — `text`, denormalized terminal status
- **`latest_email_delivery_status_at`** — `timestamptz`, status update timestamp

`invited_guests` keeps one guest record per company email.

- **`id`** — `uuid`, primary key
- **`admin_id`** — `uuid`, inviting admin/profile
- **`guest_email`** — `text`, required
- **`created_at`** — `timestamptz`, created timestamp
- **`company_id`** — `uuid`, tenant foreign key
- **Constraint** — unique guest email per company

### Viewing and analytics

`guest_viewing_logs` records guest access sessions after backend token validation.

- **`id`** — `uuid`, primary key
- **`access_code_id`** — `uuid`, related access code
- **`video_id`** — `uuid`, related video
- **`guest_email`** — `text`, denormalized guest identifier
- **`view_start_at`** — `timestamptz`, session start
- **`device`** — `text`, device or user-agent summary
- **`created_at`** — `timestamptz`, insert timestamp
- **`session_id`** — `text`, playback session identifier
- **`duration_watched`** — numeric accumulated duration

`playback_events` stores finer-grained playback telemetry.

- **`id`** — `uuid`, primary key
- **`session_id`** — `text`, playback session identifier
- **`access_code_id`** — `uuid`, related access code
- **`video_id`** — `uuid`, related video
- **`guest_email`** — `text`, denormalized guest identifier
- **`event_type`** — `text`, playback event class
- **`timestamp_seconds`** — numeric in-video timestamp
- **`created_at`** — `timestamptz`, event timestamp

## Row-Level Security (RLS)

All listed public application tables have RLS enabled. Most business entities carry `company_id`; policies compare it to `get_my_company_id()`. Administrators receive broader access, while the super-admin helper allows global scope.

<Callout kind="alert">

Browser PostgREST calls operate with the authenticated JWT and are tenant-scoped by policies. An empty result can mean no matching permitted row. Writes can fail if `WITH CHECK` rejects tenant fields.

</Callout>

## Triggers

Triggers fill in tenant context, maintain derived records, and keep denormalized status fields in sync.

- **Videos insert trigger** — supplies the actor's company when omitted
- **Poster lifecycle triggers** — run after insert or update on videos
- **Access codes insert trigger** — upserts recipient into `invited_guests`
- **Bulk invite jobs trigger** — enforces company max batch size
- **Email events trigger** — updates `access_codes.latest_email_delivery_status` from terminal events
- **Public settings triggers** — validate script integration hosts and update timestamps

## Client state management

The application uses server state rather than a global client store for most data.

- **React Query** — fetched entities, loading and error state, cache freshness, and mutation invalidation
- **AuthProvider** — session, user, and profile
- **CompanyFilterProvider** — selected company filter for admins
- **Local component state** — forms, dialogs, tabs, selection, and upload progress
- **Browser persistence** — limited to upload progress and recovery
- **PostgreSQL** — authoritative for permissions, counters, status, and relationships
