## Open the invitation

Guests do not create accounts or sign in to ScreenThis. They receive an email invitation with a link and a six-character access code, enter the code, accept terms, and watch the video within the allowed viewing window. This guide walks through the complete guest experience.

The guest receives an email containing a direct link to the video and a six-character access code.

<Steps>
  <Step title="Open the email" icon="mail" title-type="p">

  The guest opens the invitation email sent to their address.

  </Step>
  <Step title="Select the guest link" icon="link" title-type="p">

  The guest selects the link in the email, or opens the Guest Access page manually and enters the code.

  </Step>
</Steps>

## Enter the access code

The guest enters the six-character code from the email.

<Steps>
  <Step title="Enter the code" icon="key" title-type="p">

  Type the six-character access code into the input field.

  </Step>
  <Step title="Accept terms" icon="file-check" title-type="p">

  Turn on the terms-and-conditions switch to agree to the viewing terms.

  </Step>
  <Step title="Access Video" icon="play-circle" title-type="p">

  Select **Access Video** to request playback.

  </Step>
</Steps>

<Callout kind="info">

The access code is case-insensitive. If the code is not accepted, check for typos or contact the person who sent the invitation.

</Callout>

## Viewing window behavior

ScreenThis checks the viewing window, expiration, and remaining views before granting access.

<Callout kind="info">

If access begins later, the page shows a countdown and the scheduled start time.

</Callout>

<Callout kind="alert">

If access has expired, the page shows the expiration time. The guest must request new access from the person who sent the invitation.

</Callout>

<Callout kind="alert">

If all allowed views are used, the guest must request new access. The same view allowance applies across all devices.

</Callout>

## Watch the video

After access is granted, the protected player opens with the video title and invitation information. Playback is delivered through a protected embed that prevents downloading and screen recording.

## Watermarking

A viewer watermark may be shown during playback, depending on how the invitation was configured.

<Callout kind="alert">

A viewer watermark may be shown in the video stream to identify the guest. The guest should not share the code or open unnecessary simultaneous sessions — the same view allowance applies across all devices and sessions.

</Callout>
