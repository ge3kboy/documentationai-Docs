## Home dashboard overview

The Home dashboard is your central hub for everyday invitation activity. Send quick invitations, review recent activity, and manage access codes — all from one screen.

Home brings together the **Invite To View** section, **Quick Dashboard** summary cards, and the **Latest Invitations** list in one place.

## Send a quick invitation

<Steps>
  <Step title="Find Invite To View" icon="layout-dashboard" title-type="p">

  Open **Home** and locate the **Invite To View** section.

  </Step>
  <Step title="Select a video" icon="video" title-type="p">

  Search for and select a video with **Ready** status.

  </Step>
  <Step title="Enter guest details" icon="mail" title-type="p">

  Type the guest email address or select a previous guest. Then choose an access expiry date and enter the number of views allowed.

  </Step>
  <Step title="Send invite" icon="send" title-type="p">

  Select **Send Invite** and wait while ScreenThis verifies the address and sends the invitation.

  </Step>
</Steps>

<Callout kind="alert">

If an Email verification warning appears, correct the address or select **Send anyway** only when you have independently confirmed the address is correct. Addresses identified as dangerous or unusable may be blocked.

</Callout>

## Quick Dashboard

The Quick Dashboard summarizes invitation activity for the selected company and time range. It shows invitations sent, invitations accessed, and videos receiving the most guest access.

## Latest Invitations

Use the Latest Invitations list to search and filter invitation history. Open any entry to view details including the guest, video, code, expiration, views used, and delivery state.

## Manage invitations

Manage existing invitations from **Invitation Details**. Use the available action based on whether you need to send the same invitation again, issue fresh access, or stop access immediately.

### Resend an invitation

Resend sends the same active invitation email again. Use it when the guest did not receive or notice the original message.

### Reinvite a guest

Reinvite creates a fresh access code with new rules. Use it when the guest needs a new invitation instead of another copy of the existing one.

<Callout kind="tip">

Use **Reinvite** instead of **Resend** when the old code is expired, exhausted, revoked, or needs different access parameters.

</Callout>

### Revoke access

Revoke disables the current access code immediately. Use it when the guest should no longer be able to open the video with that invitation.

<Callout kind="alert">

Revoke disables the current access code immediately. The guest will no longer be able to use the code to access the video.

</Callout>
